# Behavior and motion refinements — 2026-10-02

Slate 0.1.6 (Android versionCode 7) keeps the established typography, tokens and paper treatment. Development remains in `.`.

- Markdown renders sanitized HTML, including `<br />`, underline, subscript and superscript. Obsidian highlights, inline/multiline comments, basic callouts and folded callouts work in both preview modes. Tags accept numeric prefixes, nested paths, Unicode combining characters and emoji while excluding escapes, comments, code and link destinations. Local Markdown/heading links stay in Slate, and Obsidian image-size suffixes apply to local images. This does not claim support for every Obsidian plugin or embedding syntax.
- Opening a note or notebook collapses the desktop workspace bar smoothly. Mobile notes also collapse bottom navigation. Hidden controls are inert. Reduced-motion preferences shorten transitions.
- Mobile drawers track touch displacement through CSS transforms and settle according to distance/velocity. In a note, swipe inward from the left edge for the library or the right edge for outline/links; tap the same edges as an alternative. Open drawers swipe outward to close. Vertical scrolling, multi-touch gestures, cancelled drags and input fields remain distinct.
- Clicking a live-preview paragraph retains its viewport and places the caret near the clicked text. Focus and preview reconfiguration preserve scroll snapshots. Reading-mode HTML is memoized so routine workspace updates do not reset folded callouts.
- Desktop tabs reorder by dragging, including scrolling crowded tab strips. Their context menus and Alt+Shift+Left/Right provide alternatives. Order and the active document survive relaunch; startup waits for restored session state before saving it and synchronizes the document URL.
- Fine/Medium/Bold/Heavy pen widths are 0.6/1.2/1.8/2.4. Highlighter levels also increase evenly. Existing saved stroke widths remain unchanged.
- Ink and ruled/grid/dotted paper render as SVG at every zoom level. Existing perfect-freehand curves are shared with canvas/PDF export. Vector nodes and paths are reused; selection overlays retain a bounded canvas. Pressure, undo/redo, selection transforms and saved notebook geometry are preserved.
- Mobile note menus contain Star, Export, Move, Version history and Trash. Context comes from the right drawer; switch notes from the left drawer. Settings use a bounded flex layout with fixed header/footer, a scrolling body, suitable touch targets and safe-area spacing in portrait and landscape.

## Verification

The final production standalone build passes 38 Playwright workflows, including offline reload, Markdown editing/rendering, real Chromium touch-event drawer tracking, persisted tab order, 500% vector zoom, reversible ink, PDF/DOCX/Flexcil import preservation, backup recovery, mobile insets and accessibility in light/dark layouts. The optional real Flexcil backup test was skipped because no fixture was supplied. All 39 unit tests pass. TypeScript, the provider production build, scoped ESLint and `git diff --check` pass.

Both packaged Windows native workflows pass in isolated profiles: immediate-close save/relaunch, restored document URL, pen/zoom, offline reload, backup export, save-error recovery, folder write-through, local images, rename with stable IDs, vault refresh and retention of the local workspace. The user's existing profile was not used for these tests.

Impeccable's bounded polish pass checked desktop/mobile interactions, partially dragged drawers, both settings orientations/themes and 500% ink. It corrected settings overflow and drawer padding/width while preserving the design language.

The release folder is `releases/2026-10-02-behavior`. It includes Windows/Linux x64 folders and archives, an amd64 Debian installer, independent web files/ZIP, a signed debug APK, usage instructions and SHA-256 checksums. All 692 web assets across the two desktop ASARs match the final standalone files; the Android build helper and package copy verify the APK's bundled files. Archive integrity, Debian metadata and Linux executable/sandbox modes are checked.

Linux runtime and physical Android/stylus latency were not exercised. The debug APK cannot update a release-signed Android installation; the preserved release identity requires its recovery password. Keep existing notes and profiles. Undecoded Flexcil handwriting and synchronized audio remain unsupported as documented in [flexcil-import.md](flexcil-import.md).

For independent web hosting, serve `.mjs` as JavaScript and `.wasm` as WebAssembly. The release includes a small Python localhost server with those content types. Keep the existing origin to retain browser storage.
