# Editor and organization update

Live preview and reading share the Markdown renderer and block layout. Inactive headings, lists, quotations, code, tables, links, images and math render as reading content; selecting a block reveals its editable Markdown. Tables keep the visual cell editor, and task checkboxes update their source. Reference links retain document-wide definitions. The page title is an editable filename, separate from body headings; Enter or blur commits a physical vault rename, Escape cancels, and errors retain the previous name. Edits made during a rename or move are preserved.

Link completion uses Slate panel, selection and text tokens in both themes. The sidebar can be resized with its boundary or keyboard arrows; its width persists. File/folder menus appear on hover or keyboard focus and remain visible on Android. Folder menus offer New note with Markdown/Notebook choices and Delete folder. Deletion moves the subtree into recoverable Slate Trash; it retains originals in connected vaults, matching document Trash behavior. Restoring a folder does not restore documents that were already trashed separately.

Files and folders can move through the sidebar, library cards/rows and breadcrumbs. Desktop uses drag and drop; touch uses a 400 ms long press and drag. Vault moves update physical paths and preserve cached IDs. Browser folder moves verify copied files including hidden and binary entries before removing originals. Android uses the document provider's move API; unsupported providers return an error and retain the original. Name collisions and moves into descendants are rejected.

Validation: TypeScript; 36 unit tests; 20 browser workflow tests covering matching rendered HTML and block positions, title/body preservation, task and reference links, completion contrast of at least 4.5 in each theme, sidebar persistence, folder Trash/restore, native/touch dragging, hidden descendants, Vim, tables, ink, imports, backups and accessibility. Windows Electron smoke covers save on close, persistence, offline reload, backup and connected-vault write-through/renaming. Linux is packaged but not run on this Windows host. Android 0.1.2/versionCode 3 compiles and passes APK signature and embedded asset verification; installation and provider moves on a real Android device remain unverified.

Packages: `releases/2026-10-02-editor`. Android debug signing cannot update the original release. The preserved release identity needs its recovery password. The originally reported Android parse error has not been reproduced on a device; package verification alone does not establish that it is resolved. Existing repository lint issues remain outside this change.
